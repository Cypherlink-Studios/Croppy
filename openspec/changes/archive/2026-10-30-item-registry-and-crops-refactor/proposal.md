# Proposal

## Why

Currently, item distribution commands in Croppy are fractured across multiple single-purpose subcommands (`/croppy give`, `/croppy givecan`, `/croppy givefertilizer`, `/croppy tool`), several of which lack tab-completion suggestions for tiers and item IDs. Furthermore, crop block lifecycle definitions (growth stages, environmental thresholds, harvest drops) are conflated with seed item definitions under `species/`, while fertilizers, watering cans, and tools lack a unified item configuration model and standard metadata tagging.

Consolidating all custom items into a centralized, categorized item registry (`items/<category>/<item_id>.yml`), standardizing item PersistentDataContainer (PDC) tags, renaming the crop definition directory to `crops/`, and exposing a unified `/croppy item give` command with flags and dynamic tab completion resolves these UX/DX issues and establishes a clean, extensible architectural foundation.

## What Changes

- **BREAKING**: Removed single-purpose item give commands (`/croppy give <player> <species> [amount]`, `/croppy givecan <player> <tier>`, `/croppy givefertilizer <player> <fertilizer> [amount]`, and `/croppy tool`) from the command hierarchy.
- **BREAKING**: Renamed `species/` directory to `crops/`. Crop YAMLs now strictly define world/block growth behavior, requirements, stages, display models, and harvest tables.
- **New Capability (`item-registry`)**: Introduced pure Java `ItemDefinition` and `ItemRegistry` in API/Core, and a declarative YAML item loader reading from `items/<category>/<item_id>.yml` (`seeds`, `fertilizers`, `watering_cans`, `tools`).
- **Standardized Item PDC**: Every custom item generated by Croppy is tagged with `croppy:item_id` (NamespacedKey), `croppy:category` (String), and arbitrary namespaced PDC properties configured in the item definition.
- **Unified Item Command with Flags**: Implemented `/croppy item give <category> <item_id> [quantity] [--target <player>] [--silent]` and `/croppy item list [category]`.
- **Dynamic Contextual Tab Completion**: Fixed missing suggestions by registering Incendo Cloud 2.0 `@Suggestions("item_categories")` and contextual `@Suggestions("category_items")` that filter item IDs based on the selected category.
- **Listener Unification**: Updated `CropPlantListener`, `FertilizerListener`, `WateringListener`, and `InspectionToolListener` to identify items via standardized PDC keys (`croppy:item_id` and `croppy:category`).

## Capabilities

### New Capabilities
- `item-registry`: Declarative item definition schema (`material`, `custom-model-data`, `name`, `lore`, `pdc`), categorized in-memory item registry, YAML loader for `items/<category>/*.yml`, and Paper item serialization with standardized PDC tagging.

### Modified Capabilities
- `crop-commands`: Prune legacy give commands; implement `/croppy item give` with dynamic suggestion providers, category filtering, and `--target` / `--silent` flags, plus `/croppy item list [category]`.
- `species-definitions`: Rename configuration path to `crops/`; decouple seed item configuration into `items/seeds/` while retaining crop block lifecycle and stage progression.
- `fertilizer-nutrients`: Align fertilizer item creation with `items/fertilizers/` and `ItemDefinition`, identifying fertilizer items via PDC key `croppy:item_id`.
- `watering-mechanics`: Align watering can item creation with `items/watering_cans/` and `ItemDefinition`, identifying watering can items via PDC key `croppy:item_id`.

## Impact

- **API & Core**:
  - `croppy-api`: Added `ItemDefinition`, `ItemRegistry`, and related domain records.
  - `croppy-core`: Added `DefaultItemRegistry`, `YamlItemLoader`, updated `YamlSpeciesLoader` to load from `crops/`, and integrated `ItemRegistry` into `CroppyCore`.
- **Paper Adapter**:
  - `CroppyCommands`: Replaced legacy give methods with `/croppy item give` and `/croppy item list`; implemented dynamic Cloud 2.0 suggestion providers.
  - `CroppyPlugin`: Updated file paths (`crops/` instead of `species/`, `items/` tree instead of standalone directories), initialized item registry and factory.
  - Listeners & Services: Migrated item validation from raw custom NBT/ad-hoc PDC tags to centralized `croppy:item_id` and `croppy:category`.
- **Configuration & Assets**:
  - Renamed default resources `species/wheat.yml` to `crops/wheat.yml`.
  - Created default item resources under `items/seeds/wheat_seeds.yml`, `items/fertilizers/*.yml`, `items/watering_cans/*.yml`, and `items/tools/inspector.yml`.
