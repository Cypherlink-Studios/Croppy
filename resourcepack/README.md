# Croppy Companion Resource Pack

Official client companion resource pack for the **Croppy** simulation engine on Minecraft Paper 1.21.8+.

---

## Overview

This resource pack provides client-side models, textures, GUI components, and definitions required for the immersive visual experience of Croppy:

- **Custom Item Models (`assets/croppy/items/*.json`)**: Modern 1.21.4+ item model definitions for tools, watering cans, dishes, and culinary items.
- **3D Workstation & Block Models (`assets/croppy/models/block/*.json`)**: Stove, skillet, cooking pot, and station models.
- **Custom Textures (`assets/croppy/textures/`)**: Pixel art textures for blocks, items, stations, and GUI sprites.
- **Fonts & UI (`assets/croppy/font/`)**: Custom font mappings and UI elements.

---

## Technical Specifications

- **Minecraft Version**: `1.21.8` (compatible with `1.21.7` - `1.21.8`)
- **Pack Format**: `64` (`min_inclusive: 63`, `max_inclusive: 64`)
- **Strict Mode Compliance**: Validated against Minecraft 1.21.8 strict JSON and lowercase asset path constraints (`^[a-z0-9_.-]+$`).
